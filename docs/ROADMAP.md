# Product & Engineering Roadmap

## Phase 1: MVP & UX Polish (Current)
- [x] Responsive Dashboard UI.
- [x] Static Data Integration (Colleges & Exams).
- [x] Client-side Routing and Protected Routes.
- [x] Vercel Deployment & SPA Routing Fix.
- [x] Database Schema Design (Prisma) and Seeding.

## Phase 2: API Integration & Backend Swap (Next 3 Months)
- [ ] Deploy Express.js backend to production (Railway/Render).
- [ ] Swap frontend `src/api/mocks` with `axios` or `fetch` calls to the live API.
- [ ] Implement robust JWT-based Authentication (replacing `localStorage` mock auth).
- [ ] Migrate User Profile data to the PostgreSQL database.

## Phase 3: Advanced Features (Next 6 Months)
- [ ] **Predictive AI Engine:** Calculate admission probabilities based on mock test scores and historical cut-offs.
- [ ] **Social Features:** Allow users to share their "College Lists" or Compare charts with friends and parents.
- [ ] **Push Notifications:** Web Push APIs for exam registration deadlines.

## Phase 4: Scale & Monetization (Next 12 Months)
- [ ] B2B Dashboard for High School Counselors to track their students.
- [ ] Direct application portals for partnered private universities.
